# CS 340 Study Kit

An unofficial study kit for BYU CS 340 (Software Design), Fall 2026 (TTh sections).

- **Midterm 2** (Code Reuse through API Gateway): https://jarobinson-121.github.io/cs340-study-kit/
- **Midterm 1** (TypeScript through UI Architecture): https://jarobinson-121.github.io/cs340-study-kit/midterm-1.html

A switch at the top of each page moves between the two exams. Each kit has:

- **Study guide**: condensed notes for every topic on that exam
- **Diagrams**: drawn UML and architecture diagrams with "check yourself" questions
- **Flashcards** with a topic filter
- **True / False** and **Multiple choice**: bubble-sheet style, three forms (A, B, C) of different questions on the same topics, graded all at once
- **Essay**: written prompts with grading points and model answers
- **Code writing**: handwritten TypeScript problems with grading points and model answers

Your answers and drafts are saved only in your own browser, separately for each exam.

Built from the materials linked in the [course schedule](https://github.com/BYU-CS-340/softwaredesign/blob/main/schedule/schedule-fall-2026-tth.md). Not an official course resource.
