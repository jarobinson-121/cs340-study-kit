# CS 340 Midterm 1 Study Kit

An unofficial study kit for BYU CS 340 (Software Design), Fall 2026, covering everything on Midterm 1: TypeScript fundamentals through User Interface Architecture.

**Open it:** https://jarobinson-121.github.io/cs340-study-kit/

What's inside:

- **Study guide**: condensed notes from each topic's lecture slides
- **UML diagrams**: drawn examples of every class-diagram notation from the slides, plus Observer, package and sequence diagrams
- **Flashcards**: 79 cards with a topic filter
- **True / False** and **Multiple choice**: bubble-sheet style sections you grade all at once, each with three forms (A, B, C) of different questions on the same topics
- **Essay**: written prompts with grading points and model answers
- **Code writing**: handwritten TypeScript problems with grading points and model answers

Your answers and drafts are saved only in your own browser.

Built from the slides linked in the [course schedule](https://github.com/BYU-CS-340/softwaredesign/blob/main/schedule/schedule-fall-2026-tth.md). Not an official course resource.
